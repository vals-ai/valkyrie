Each task runs in a sandbox: a separate environment for the agent and task. Sandboxes
run in your organization's Daytona or Modal account.

- Connect a provider once, and everyone in the organization can use it.
- Save the provider's credentials in Valkyrie, then connect the provider to them.

## Set up Daytona

1. [Create a Daytona API key](https://app.daytona.io/dashboard/keys) with read, write, and
   delete access to sandboxes and snapshots.
2. Choose a target from Daytona's
   [shared regions](https://www.daytona.io/docs/regions#shared-regions).
3. Save the key, API URL, and target in `daytona.json`:

   ```json
   {
     "DAYTONA_API_KEY": "API_KEY",
     "DAYTONA_API_URL": "https://app.daytona.io/api",
     "DAYTONA_TARGET": "us"
   }
   ```

   Replace *`API_KEY`* with your Daytona API key.

4. Upload the credentials and connect Daytona:

   ```bash
   valkyrie secret set daytona-credentials < daytona.json

   valkyrie provider set daytona daytona-credentials
   ```

## Set up Modal

1. [Create an API token](https://modal.com/settings/tokens)
   under **Settings > Tokens > API tokens**, in the Modal workspace where you want the
   sandboxes to run. Modal shows the token once, as a command:

   ```bash
   modal token set --token-id ak-... --token-secret as-...
   ```

2. Save the token ID and secret from that command in `modal.json`:

   ```json
   {
     "MODAL_TOKEN_ID": "ak-...",
     "MODAL_TOKEN_SECRET": "as-..."
   }
   ```

3. Upload the credentials and connect Modal:

   ```bash
   valkyrie secret set modal-credentials < modal.json

   valkyrie provider set modal modal-credentials
   ```

## Choose the provider for a run

Choose a provider when starting a run:

```bash
valkyrie run start --agent my-agent --benchmark swebench --provider modal
```

- Without `--provider`, runs use your default. If you haven't set a default, they use
  Daytona.
- Your default applies only to you in the current organization.

To set your default, sign in and run:

```bash
valkyrie provider default modal
```

To see connected providers and your default:

```bash
valkyrie provider list
```

## Rotate or remove credentials

To replace credentials, save the new values under the same secret name:

```bash
valkyrie secret set modal-credentials < modal.json
```

To disconnect a provider:

```bash
valkyrie provider remove modal
```

Runs using that provider will fail until you connect it again.

## Limits

- Modal sandboxes last at most 24 hours, so a longer task fails on Modal.
- If a benchmark reports `Modal sandbox provider is not implemented`, ask its author to
  update the benchmark service.
- Docker sandboxes are available only on a [local
  Tracker](/self-hosting/local-tracker#docker-sandboxes).
