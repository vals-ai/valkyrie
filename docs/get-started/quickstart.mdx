This quickstart runs Claude Code on one Terminal-Bench task on hosted Valkyrie, in a Modal sandbox. To run the Tracker on your own machine instead, follow [Run Tracker locally](/self-hosting/local-tracker).

You need:

- [uv](https://docs.astral.sh/uv/) and a Vals AI account. To request one, email [contact@vals.ai](mailto:contact@vals.ai).
- A [Modal](https://modal.com) account for task sandboxes.
- An [Anthropic API key](https://platform.claude.com/settings/keys) for Claude Code.

## 1. Install the CLI

```bash
uv tool install valkyrie-cli
```

It installs as `valk`, with the long name `valkyrie`.

## 2. Sign in and choose an organization

```bash
valk login
```

If a teammate already set up your organization, join it instead of creating one:

- If they invited you, run `valk org accept ORG_ID`. See [Join an organization](/get-started/configuration#join-an-organization).
- If you already belong to it, run `valk org use ORG_ID`.

Otherwise, create one, replacing `my-team` with an unused [organization ID](/get-started/configuration#create-an-organization):

```bash
valk org create my-team
```

## 3. Connect Modal

Follow [Set up Modal](/get-started/sandbox-providers#set-up-modal) to save your token and connect your workspace. It's set once per organization.

## 4. Save your API key

```bash
valk secret set ANTHROPIC_API_KEY
```

Enter the key when prompted. It is hidden as you type.

## 5. Install Claude Code and a dataset

Install the [Claude Code example](https://github.com/vals-ai/public-agent-registry/tree/main/examples/claude_code-v1.0.0) from the public agent registry, and Terminal-Bench 2 from Harbor as the dataset `tb/tb2`:

```bash
valk agent install \
  https://github.com/vals-ai/public-agent-registry/tree/main/examples/claude_code-v1.0.0

valk dataset install tb/tb2 terminal-bench/terminal-bench-2 --location harbor
```

## 6. Run one task

```bash
valk run start --agent claude_code-v1.0.0 --dataset tb/tb2 \
  --model anthropic/claude-sonnet-4-6 --provider modal \
  -s ANTHROPIC_API_KEY ANTHROPIC_API_KEY --slice 0:1 --follow
```

- `-s` sets the agent's `ANTHROPIC_API_KEY` from the secret you saved under that name.
- The CLI prints a **Run ID** and streams progress until the run finishes, which can take 10 minutes or more.
- To run more tasks at once, raise `--slice` and `--concurrency`, for example `--slice 0:10 --concurrency 10`.

## 7. Read the result

```bash
valk run show RUN_ID
```

Replace *`RUN_ID`* with the ID from the **Run ID** line. **Final score** is the share of tasks that passed.

To browse your organization's runs, tasks, and logs, run `valk tui`.
