Run Claude Code on one Terminal-Bench task with Vals AI's hosted Valkyrie.

You need:

- Python 3.12, [uv](https://docs.astral.sh/uv/), and Git.
- A [Modal](https://modal.com) account for task sandboxes.
- An [Anthropic API key](https://platform.claude.com/settings/keys) for Claude Code.

<a id="install-the-cli" style={{ display: "block", scrollMarginTop: "12rem" }} />

## 1. Install the CLI

```bash
uv tool install valkyrie-cli
```

<a id="sign-in" style={{ display: "block", scrollMarginTop: "12rem" }} />

## 2. Sign in and create an organization

```bash
valkyrie login

valkyrie org create my-team
```

- Replace `my-team` with an unused organization ID. See the
  [ID requirements](/get-started/configuration#create-an-organization).
- Later commands use this organization.

## 3. Connect Modal

Follow [Set up Modal](/get-started/sandbox-providers#set-up-modal) to save your token and
connect your workspace to Valkyrie.

## 4. Install Claude Code

Install the [Claude Code example](https://github.com/vals-ai/public-agent-registry/tree/main/examples/claude_code-v1.0.0)
from the public agent registry:

```bash
valkyrie agent install \
  https://github.com/vals-ai/public-agent-registry/tree/main/examples/claude_code-v1.0.0
```

- The CLI confirms that `claude_code-v1.0.0` is installed in your organization's library.

Save your Anthropic API key:

```bash
valkyrie secret set anthropic-api-key
```

Enter the key when prompted. It is hidden as you type.

## 5. Install a Harbor dataset

```bash
valkyrie dataset install tb/tb2 terminal-bench/terminal-bench-2 --location harbor
```

- The tasks are saved as `tb/tb2` in your organization.

<a id="run-one-task" style={{ display: "block", scrollMarginTop: "12rem" }} />

## 6. Run one task

```bash
valkyrie run start --agent claude_code-v1.0.0 --dataset tb/tb2 \
  --model anthropic/claude-sonnet-4-6 --provider modal \
  -s ANTHROPIC_API_KEY anthropic-api-key --slice 0:1 --concurrency 1 --connect
```

- Valkyrie creates a Modal sandbox, runs Claude Code on one task, and grades the result.
- The CLI prints a **Run ID** and streams progress until the run finishes.

<a id="read-the-result" style={{ display: "block", scrollMarginTop: "12rem" }} />

## 7. Read the result

```bash
valkyrie run results RUN_ID
```

Replace *`RUN_ID`* with the ID from the **Run ID** line.

- The CLI prints the saved results file's path.
- Open that JSON file to inspect the task's result and score.
