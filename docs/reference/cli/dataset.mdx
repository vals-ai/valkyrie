## `valkyrie dataset create` {#create}

Create a dataset in a benchmark.

BENCHMARK must already exist. `valkyrie dataset push` creates a missing one. NAME is lowercase letters and digits with single '.', '_' or '-' separators, such as verified.

```bash Syntax
valkyrie dataset create \
  <BENCHMARK> \
  <NAME> \
  [--description <TEXT>]
```


## `valkyrie dataset tag` {#tag}

Point a tag at a version of a dataset. The version is the latest one unless the reference ends in @ and a revision number, a tag or a digest.

A tag that points at another version moves only with --force. The latest tag always moves.

A tag is lowercase letters, digits, hyphens and dots, starts with a letter or digit, and can't be a whole number or start with sha256:.

```bash Syntax
valkyrie dataset tag \
  <BENCHMARK/DATASET[@VERSION]> \
  <TAG> \
  [--force]
```

```bash Example
valkyrie dataset tag \
  swe-bench/verified@2 \
  stable
```
