## `valkyrie completion` {#completion}

Print completion scripts for both valkyrie and valk.

Bash: add eval "$(valkyrie completion bash)" to ~/.bashrc.

Zsh: add eval "$(valkyrie completion zsh)" after compinit in ~/.zshrc.

Fish: add valkyrie completion fish | source to ~/.config/fish/config.fish.

Nushell: save valkyrie completion nu to ~/.config/nushell/valkyrie.nu, then source that file from config.nu.

```bash Syntax
valkyrie completion \
  <SHELL>
```
