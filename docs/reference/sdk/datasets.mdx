## `client.datasets.push` {#push}

Publish the task folders under ``folder`` as a version of the dataset, creating it and its benchmark if they are missing.

Only the tasks whose files the dataset does not store yet are uploaded, so pushing an unchanged folder uploads nothing and returns the version it already made. ``on_stored`` hears each task that was uploaded, ``on_created`` the name of each resource this call created, ``on_left_out`` each task and the entries in its folder that are not part of a task and so are not stored, and ``on_warning`` what a dataset.toml in ``folder`` leaves out or names differently.

A dataset.toml in ``folder`` is a lock: the version holds exactly the tasks it lists, each task's files must still hash to the digest it lists, and its version label becomes a tag.
